# 智能客服系统运维手册

本手册面向负责智能客服系统日常运维的工程师，覆盖部署、配置、监控与故障处理。

## 环境准备

### Python 版本要求

系统要求 Python 3.10 或以上版本。低于 3.10 的版本缺少结构化模式匹配语法，启动时会直接报语法错误。推荐使用 3.11，在异步场景下性能提升明显。

### 依赖安装

执行 `pip install -r requirements.txt` 安装全部依赖。若公司内网无法访问 PyPI，请配置镜像源：`pip config set global.index-url https://mirrors.aliyun.com/pypi/simple/`。

## 配置说明

### API Key 配置

在项目根目录创建 `.env` 文件，填入 `LLM_API_KEY=你的密钥`。密钥可以在控制台的凭证管理页面申请。注意 `.env` 文件绝对不能提交到代码仓库，否则密钥会随提交历史永久泄漏，即使后续删除文件也无法从历史中彻底清除。

### 检索参数调优

`TOP_K` 控制每次检索返回的文本块数量，默认值为 5。调大会引入更多上下文但也会增加 token 消耗和噪声。`CHUNK_SIZE` 控制切分粒度，默认 500 字符。技术文档中命令块和表格较多时建议适当增大到 800，避免命令被切断。

### 超时设置

`REQUEST_TIMEOUT` 默认 60 秒。若模型响应经常超时，应先排查网络链路而不是盲目调大该值，因为超时往往意味着上游服务已经异常。

## 故障处理

### 服务无法启动

首先查看启动日志中的 `engine_error` 字段。最常见的原因是 API Key 未配置，此时引擎会以降级状态启动，业务接口返回 503 而配置接口仍然可用，可以直接通过页面补填密钥。

### 检索结果为空

按以下顺序排查：确认知识库中已有文档；确认嵌入模型未被中途更换，因为更换模型会导致向量库重建并清空；确认相似度阈值 `MIN_SIMILARITY` 没有设置得过高。

### 回答内容与文档无关

这通常是检索阶段召回了不相关的文本块。中文知识库如果误用了纯英文的嵌入模型，检索结果会接近随机，这是最容易被忽略的一类配置错误。可以调用检索接口单独查看召回的片段和相似度分值来确认。

## 长段落测试专区

这一段是刻意写成的超长中文段落，用来验证切分逻辑对没有空格的连续中文文本是否生效，因为中文的书写习惯里词与词之间不存在空格分隔符，如果切分实现依赖按空白字符分词的方式来处理超长文本，那么整个段落会被当作一个不可再分的整体原样返回，最终产生一个远远超过预设块大小上限的巨型文本块，这个块在后续向量化时可能超过嵌入模型的最大输入长度而被静默截断，导致段落后半部分的内容根本没有进入索引，用户提问时自然永远检索不到，而这种失败是完全静默的，日志里不会有任何异常信息，排查起来极其困难，因此必须用真实的中文长段落来覆盖这条路径，确认切分器会在标点处正确断开，并且每一个产出的文本块长度都不超过配置的上限值，同时还要确认相邻文本块之间保留了配置要求的重叠字符数，以免跨块的语义被硬生生切断从而影响检索召回的准确性。
